MCHOSE A5 Pro Max Driver

A5 Control is an independent browser driver for the first-generation MCHOSE A5 Pro Max gaming mouse released in 2023. Configure the mouse directly in desktop Chrome or Edge without installing permanent background software.

Configure your MCHOSE A5 mouse online

The web driver reads and writes the mouse's onboard memory through WebHID. It supports the wired mouse, 1K wireless receiver and 4K wireless receiver.

  • Set up to six DPI stages and their indicator colors.
  • Change polling rate, debounce, lift-off distance and sleep time.
  • Manage onboard profiles and remap the six physical buttons.
  • View battery level and mouse or receiver firmware versions.
  • Automatically reconnect approved hardware and handle mouse standby.

Browser requirements

Use Google Chrome or Microsoft Edge on a desktop computer. The first connection requires the browser's device permission prompt. All settings communication remains between this page and the selected USB HID device.
